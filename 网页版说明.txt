========================================================
        集装箱装箱计算 · 网页版 使用/部署说明
========================================================

网页版由两个文件组成：
    app.py          —— 网页界面（Streamlit + Plotly 交互式3D + Excel/JSON 导出）
    packer_pro.py   —— 装箱计算内核（标准版 / 增强版遗传搜索）
依赖清单：requirements_web.txt


────────────────────────────────────────────────────────
一、你自己本地试运行
────────────────────────────────────────────────────────
Windows：双击  run_web_app.bat
Mac：    双击  run_web_app.command
        （若提示"无法打开"，右键 → 打开；或终端里执行 bash run_web_app.command）

首次运行会自动建环境、装依赖（几分钟），随后浏览器自动打开
http://localhost:8501 。用完关掉黑窗口即可。


────────────────────────────────────────────────────────
二、怎么让【Mac 客户】用上（客户无需装任何环境）
────────────────────────────────────────────────────────
网页版最大的好处：客户只需要一个浏览器。推荐下面这条零安装路线。

▶ 方案A（最推荐）：部署到 Streamlit Community Cloud（免费）
  客户只要点一个网址就能用，Windows/Mac/手机都行，你无需有 Mac。
  步骤：
    1. 注册 GitHub，把 app.py、packer_pro.py、requirements_web.txt
       传到一个新仓库（可设为私有）。
    2. 打开 https://share.streamlit.io ，用 GitHub 登录，
       选择该仓库、主文件填 app.py，点击 Deploy。
    3. 几分钟后得到一个网址（形如 https://xxx.streamlit.app），
       把网址发给客户即可。
  注意：数据会经过云端。若装箱数据涉密，请用方案B或C。

▶ 方案B：你本机运行，客户远程访问（临时演示很方便）
  你本机按"一、"跑起来后，用一个内网穿透工具（如 ngrok）把
  localhost:8501 暴露成一个临时公网网址发给客户。你关机即失效。

▶ 方案C：客户内部服务器自建（适合企业、数据不外发）
  把这三个文件放到客户的一台服务器上，运行：
      pip install -r requirements_web.txt
      streamlit run app.py --server.port 8501 --server.address 0.0.0.0
  客户内网用浏览器访问  http://服务器IP:8501 。


────────────────────────────────────────────────────────
三、网页版怎么用
────────────────────────────────────────────────────────
1. 「① 集装箱尺寸」：直接在长/宽/高三个输入框里填米数。
2. 「② 货物清单」：在表格里逐行填 长/宽/高/数量/重量，类型用下拉选
   木箱/纸箱/托盘（不用记数字代码）。每行最右侧有 🗑 按钮可删除该行
   （会弹出确认，可勾选“本次不再提示”）；下方有 ➕添加一行 / 🧹清空 / ↺载入示例。
   页面默认给了一份示例数据，改成你自己的即可。
3. （可选）「📥 从文件/文本导入」：仍支持上传旧的 txt/xlsx 或粘贴文本，
   点“导入到表格”后会自动填进上面的表格，核对无误再算。

3b.【间断录入】货物清单下方有「⬇ 导出货物清单」，可选 txt 或 xlsx 格式导出当前录入内容
   （含集装箱尺寸）。下次打开用上面的“导入”读回来即可继续编辑，不必重新输入。
   导出的 txt 带中文注释、xlsx 第7列有中文类型，均可直接用记事本/Excel 编辑后再导入。
4. 「实时预估」：填表过程中，页面会即时显示货物件数、总体积、占集装箱比例、
   总重，并给出预警（体积超箱、单件超尺寸、重货只能放底层等），不用点计算就能看到。
5. 左侧「③ 计算参数」：设重量阈值；选【标准版】(快) 或【增强版】(搜索逼近最优，可设时间)；
   点「开始计算」。
6. 右侧看结果：装载率等指标、可旋转/缩放/悬停的 3D 图、装箱清单表格。
   3D 图上方每个类别是一个按钮（如“类别1·纸箱”），点击切换高亮显示，
   另有“全选/全不选”；图例也会显示具体类型（木箱/纸箱/托盘）。
7. 「逐层查看」滑块：拖动可从底层往上逐层显示箱子，直观看装载顺序；拉到最高显示全部。
8. 底部可下载 Excel 装箱清单 和 JSON 方案。

9. 查看历史方案：左侧「查看已保存方案」上传之前下载的 packing_plan.json，
   点“📂 载入方案查看”，即可在右侧重现该方案（无需重新计算）。


────────────────────────────────────────────────────────
四、备注
────────────────────────────────────────────────────────
· 标准版结果与最初版一致；增强版保证不劣于标准版并尽量逼近最优。
· 命令行版(packer_pro.py 直接运行) 仍可用，适合本地快速计算。
· 如需减少依赖体积，可把 packer_pro.py 里对 matplotlib 的导入改为按需导入
  （网页版本身只用 Plotly，不用 matplotlib）——需要的话我可以帮你改。
