========================================================
  打包与分发说明（给你自己看，不是给客户）
========================================================

目标：把装箱程序做成客户免安装、双击即用的软件，且体积小、启动快。


为什么之前打出来有 3GB？
--------------------------------------------------------
因为是在“臃肿”的 Python 环境里打包的（比如 Anaconda，或装过
scipy / pandas / PyQt / torch 等的环境），PyInstaller 会把这些无关的
大库和 numpy 的 MKL(约 1GB) 一起卷进去。

解决办法（新版 build_exe.bat 已内置）：
  1) 在一个全新的“干净虚拟环境”里打包，只装 matplotlib / numpy / openpyxl，
     其它一律隔离在外 —— 体积通常从 3GB 降到 150~250MB。
  2) 打成“文件夹版”而不是“单文件版” —— 启动是秒开。
     （单文件版每次启动都要先把几百 MB 解压到临时目录，所以又慢又卡。）


一、生成程序（在你自己的 Windows 电脑上，只需做一次）
--------------------------------------------------------
1. 确认本文件夹里有 packer_optimized.py。
2. 双击运行  build_exe.bat
3. 它会自动创建干净环境、装依赖、打包（几分钟）。
4. 完成后，程序是一个文件夹：  dist\ContainerPacker\
   里面的  ContainerPacker.exe  就是可执行程序。

想打包“最初版”而非优化版？把 build_exe.bat 最后一行的
packer_optimized.py 改成 packer.py 即可。


二、发给客户什么
--------------------------------------------------------
“文件夹版”必须【整个文件夹一起发】，不能只发那个 exe。做法：
  1) 把一个数据文件（如 data-xxx.txt）和 客户使用说明.txt
     复制进  dist\ContainerPacker\  文件夹里；
  2) 把整个  ContainerPacker  文件夹压缩成一个 zip；
  3) 把 zip 发给客户。客户解压后，双击里面的 ContainerPacker.exe 即可。


三、体积还想更小？
--------------------------------------------------------
150~250MB 已是 matplotlib+numpy 这类程序的正常下限，主要体积来自绘图库本身。
若要显著再小（几 MB 级），只能改变绘图方式（例如不用 matplotlib 实时窗口，
改成生成图片文件），那属于程序改造，需要的话告诉我，我可以帮你做一版
“轻量绘图”的版本。


四、常见问题
--------------------------------------------------------
· 杀毒软件误报：PyInstaller 程序的常见现象，加信任即可；文件夹版比单文件版更少被误报。
· 一定要在完整版官方 Python(python.org) 下打包，某些精简版缺 tkinter，
  会导致三维窗口打不开。
· 只能在 Windows 上运行；客户是 Mac 需在 Mac 上另行打包。
· 发之前务必自己在“干净文件夹/干净电脑”上先跑通一遍再发客户。
