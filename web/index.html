使用说明 —— 这是什么、怎么用（首次使用请先看这里）

这是什么

一个集装箱三维装箱计算工具。你告诉它集装箱的尺寸和要装的货物（尺寸、数量、重量、类型）， 它会自动算出每一件货放在哪里、怎么摆，以空间利用率为首要目标，并给出三维图和可下载的装箱清单。

计算时会自动遵守这些实际装载规则：

  • 底层优先（软规则）：可选择让「重的」或「体积重(密度)大的」货物优先放到底层；这是偏好而非硬性限制，实在放不下时仍允许叠放。
  • 禁止倒放（硬规则）：在货物清单里勾选「禁止倒放」的货物，落地面固定为长×宽、高度只能是原始高度。
  • 支撑规则：任何不落地的货物，底面中心正下方必须有货物托住（重心有支撑），不会悬空或倾倒；横跨两件货物摆放也可以。
  • 两种工作模式：自动模式由程序按所选指标决定底层优先；手动模式由你为每类货物设定「优先级」，优先级高的放底层。

怎么用（5 步）

  1. 填集装箱尺寸：点选 20GP / 40GP / 40HQ，或手动填写长、宽、高（单位：米）。
  2. 填货物清单：逐行填写长/宽/高/数量/重量，类型可选木箱 / 纸箱 / 托盘；每行最右侧可删除该行。 也可展开「从文件 / 文本导入」批量导入 txt / xlsx。
  3. 设参数：选择工作模式、底层优先指标与计算模式。标准版快速稳定； 增强版把同类货物拼成整齐的块，用束搜索同时比较多种摆法，时间越长通常越紧密（可设搜索时间上限，全部装入会提前结束）。
  4. 点「开始计算」。计算在服务器上进行，期间可随时取消。
  5. 看结果 & 导出：查看装载率、三维图与清单，可下载 Excel 装箱清单 与 JSON 方案。

结果怎么看

  • 实时预估：还没计算时就会显示件数、总体积、占集装箱比例、总重，并预警「体积超箱 / 单件超尺寸 / 重货」。
  • 三维图：鼠标左键旋转、右键平移、滚轮缩放（手机上单指旋转、双指缩放）；悬停可看单件详情。
  • 类别图例：点击图例切换该类货物的高亮，数量显示的是本方案实际装入的件数（未装满时显示「已装 / 应装」）。
  • 分段查看：长/宽/高三个方向各有一个两端滑块。实际装柜沿长度方向从一端装到另一端， 拖动「长度方向」的左端或右端，就能模拟从前往后或从后往前的装载过程。

常见问题

  • 录到一半关掉页面会丢吗？不会。清单和最近一次结果会自动保存在本机浏览器里，下次打开自动恢复。 需要换电脑时，用「导出当前清单」存成 txt / xlsx，再导入即可。
  • 想回看以前算过的方案？在「查看已保存方案」选择之前下载的 packing_plan.json 或 packing_plan.xlsx，无需重算。
  • 提示装不下怎么办？程序会优先提高已装体积，并告诉你装了多少。可尝试增强版、增加搜索时间、加大集装箱尺寸或减少货量。
  • 长宽填反了有影响吗？没有。程序会自动尝试多种朝向并取更优结果。
